# Changelog

All notable changes to these plugins will be documented here.

## 1.1.0

- Turned the repository into a two-plugin Cursor marketplace, with `.cursor-plugin/marketplace.json` at the root.
- Moved the Unified.to workspace plugin to `plugins/unified-to/`. Its manifest, MCP config and logo are unchanged.
- Added the `unifiedmodels` plugin in `plugins/unifiedmodels/`, pointing at `https://api.unifiedmodels.com/mcp` (OAuth 2.1 with DCR and PKCE).

## 1.0.0 — initial release

- Added the `unified` MCP server pointing at `https://mcp-api.unified.to/mcp` (OAuth 2.1 with DCR and PKCE).
